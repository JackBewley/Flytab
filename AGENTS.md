Preserve the minimal permission and privacy model: tabs, storage, favicon; no host permissions, content scripts, external network requests, analytics, or incognito. Outside the list, Option+F must toggle the previous MRU tab immediately with no popup or release dependency. The toolbar always toggles immediately. The visual flow is hold Option+Shift, press F to open, keep BOTH modifiers held while tapping F to advance, release both to commit and close. Shift NEVER reverses F. Both configured shortcuts advance inside the list and wrap. Escape must cancel while modifiers remain held. Enter/click remain fallback commit paths. Preview never activates or reorders tabs. Capture modifier releases before the UI module loads and commit only when all modifier flags are false. Releasing F while modifiers remain held must not commit. While the popup owns its authenticated input Port, suspend the background command listener and handle configured modified chords in the DOM exactly once. Chromium swallows keyups after a browser-handled accelerator; do not restore background command routing during preview. Do not claim recovery of releases that happen before the popup receives input, and do not guess modifier state with a timer. Retain command IDs for saved bindings: switch-next toggles outside the list, switch-previous opens it, and both advance inside it. The user explicitly rejects a separate helper app.

The pinned fast path temporarily configures an action popup and immediately clears that configuration after opening to preserve toolbar clicks. Unpinned/unsupported cases use the native window. Action cleanup must close the extension document, NEVER remove its owning browser window. In real Chrome an action sender may omit tab/documentId, its POPUP context may report windowId=-1, and its owner window may report focused:false while the document has focus; validate the live exact-URL context and owner identity. Do not reintroduce top-level await of initial state in popup.js: openPopup waits for document load while the initial message waits behind the opening operation. Capture input first, then start the initial request, focus independently, and preserve serialized moves/commits.
